# P3 — 内容素材库 + 模板

> 版本：v0.2 P3。状态：设计定稿。
> 目标：历史内容可检索/复用，常用文体用模板快速起稿。

---

## 1. 背景与问题

用户重复起稿效率低，历史发布的内容无法快速检索与再次使用；常见文体（活动公告/测评/科普）每次从零写结构。

---

## 2. 方案

### 2.1 内容素材库（发布历史升级）

现有发布历史已存 `{ title, body, timestamp, results }`（最多 50 条）。升级为「内容库」：

- **全文检索**：按标题/正文关键字过滤
- **复制**：一键复制标题+正文
- **再次使用**：点击填入编辑区（title/body），可直接改后发布

### 2.2 快捷模板

内置常用文体模板（结构化骨架），点击填入正文，再补内容：

| 模板 | 结构 |
|---|---|
| 活动公告 | 背景 → 活动内容 → 时间/地点 → 参与方式 |
| 产品测评 | 开箱/初印象 → 优缺点 → 使用体验 → 购买建议 |
| 知识科普 | 概念引入 → 原理讲解 → 案例 → 总结 |
| 观点短评 | 观点 → 论据 → 反方 → 结论 |

---

## 3. 技术设计

### 3.1 内容库（`popup` 历史 modal 升级）

- 现有 `showHistoryModal` 增加搜索框（`historyKeyword` state），过滤 `title`/`body`
- 每条记录增加「复制」「再次使用」按钮
- 「再次使用」→ `setTitle`/`setBody` + 关闭 modal

### 3.2 模板（`popup` 编辑区）

- 新增 `CONTENT_TEMPLATES` 常量（id/name/structure）
- 编辑区顶部「模板」下拉/按钮 → 选中后填入正文骨架（Markdown）

---

## 4. 验收标准

1. 内容库可按关键字检索历史
2. 历史内容可复制、可再次使用（填入编辑区）
3. 模板库可一键填入正文骨架
4. 纯前端能力，无新增依赖、无网络调用

---

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 历史含 media dataUrl 超配额 | 沿用"媒体仅存元数据"策略，复制/复用仅复制文本 |
| 模板内容泛化 | 模板只给结构骨架 + 占位符，用户填充 |
